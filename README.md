<h1>Aruba CX Series Switch Remote SFlow Collector Setup</h1>
  <h3>Does what it says on the tin. Creates the specified collector IP in the switch you specify. You have the have a CX_PASS environment variable for it to be able to log in.</h3>

`Usage: /usr/local/bin/sflowenable-arubacx.py [-d|--debug] <switch_ip> [collector_ip] [username]`
